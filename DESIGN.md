# HackRadar design system

The interface aims for Stripe-level craft without copying Stripe assets: bright paper, precise typography, fine rules, expressive gradients, restrained shadows, and dense information that still breathes.

Country selection changes the accent system and market context. Rankings remain the visual center. The Three.js radar is playful supporting motion, never a gate to content. Respect reduced motion, keep native controls and semantic headings, and preserve original-link visibility.

Responsive behavior collapses the hero and ranking rows into a single reading column, keeps controls full-width, and prevents horizontal page overflow. Status color is never the only signal; effort and source state always have text labels.

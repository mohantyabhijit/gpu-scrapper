# Rules and disclosure

HackRadar was built for the Scrape-Verse submission using public data and Bright Data Scraper Studio as a core runtime and recovery component. The product, repository, source model, and demo are publicly inspectable.

- Scraping is limited to public signed-out event pages.
- No personal/private/account/paywalled/restricted/government data is collected.
- Original URLs and verification dates are preserved.
- AI was used for research assistance, implementation, testing, and bounded Studio prompt generation. The participant owns product direction, credentials, final review, submission attestations, and explanation of the work.
- Historical Raster code and commits are preserved but are not presented as the current product.

The participant must personally confirm subjective form ratings, legal attestations, and final submission before sending the form.

# Source eligibility

| Source | Public target | Decision | Reason |
| --- | --- | --- | --- |
| Devpost | Upcoming public online hackathons | Approved | Signed-out event cards/details, global eligibility and prize data |
| Unstop | Public hackathon directory | Approved with row filtering | Useful India coverage; exclude quizzes, assessments, and prelim-only contests |
| Hackathons UK | Public events directory | Approved | Public UK event listings and permissive crawl policy |

Collectors must respect public site policy, bounded rates, and exact targets. A source approval does not make every returned row eligible. Rows still need genuine build-event identity, a public canonical link, usable schedule, and provenance.

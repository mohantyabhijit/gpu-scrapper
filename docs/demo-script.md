# Judge demo script (draft)

Target length: two to three minutes, terminal-first.

1. **Frame impact (15s).** Open Raster and state that it replaces the regional
   GPU-price tab hunt across the US, UK, India, and Singapore without pretending
   to be the merchant.
2. **Show the pipeline (30s).** In the terminal, run the redacted collector
   command for an allowlisted source and show the stable `c_*` ID, valid row
   count, currency, and timestamp. Do not show credentials or raw headers.
3. **Show the product and originality (35s).** Switch markets, show that USD,
   GBP, INR, and SGD are never ranked together, open a model page, and follow an
   attributed retailer link. Point out freshness and “verify on retailer” copy.
4. **Show the hero proof (35s).** Display the sanitized failing contract,
   `bdata scraper heal` preview, approval, and rerun. Highlight that the exact
   Collector ID is unchanged and the downstream storefront code was untouched.
5. **Show automation (20s).** Open the GitHub Action summary for a scheduled or
   manual run: per-source validation, counts, and degraded handling; no secret
   output.
6. **Close against the rubric (15s).** Summarize impact, the market-isolated
   collection approach, technical safety, Scraper Studio centrality, and the
   same-ID repair. A failed source stays stale/degraded instead of erasing good
   data, and shoppers verify final price and stock at the retailer.

Rehearse from a clean signed-out browser and a terminal with masked output.
Fixtures may be used only when visibly labelled as fixtures.
